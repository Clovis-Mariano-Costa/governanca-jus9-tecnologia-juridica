# Decisoes incorporadas a governanca

## 1. Incorporado sem alterar Constituicao

Este pacote incorpora regras operacionais abaixo da Constituicao.

Nao foi feita nova alteracao constitucional nesta etapa, porque alteracoes constitucionais exigem cuidado reforcado e, quando subirem de nivel, devem ser confirmadas pelo Fundador.

## 2. Regras incorporadas

### DNA

O DNA juridico passa a ser entendido como arquitetura de:

- identidade;
- limite;
- continuidade;
- classificacao;
- responsabilidade;
- autoria;
- memoria;
- fonte primaria.

### Classificacao

Foi consolidada a matriz:

- PUBLICO;
- SIGILOSO;
- SECRETO;
- COFRE.

### IA

A forma canonica preservada e:

`I.A generativa multimodal jurista com governanca humana`

### API e casa publica

Foi preservada a regra:

- chave/API/token nunca no front-end;
- segredo apenas em ambiente seguro;
- fallback local pode existir, mas nao deve ser confundido com API real.

### Genealogia

Foi consolidada a separacao:

- genealogia publica simbolica reduzida;
- genealogia privada protegida;
- cofre nao publicado.

### Sagrado

Foi incorporada a regra de cautela maxima para representacoes visuais de Deus/Deusa/DEUS DOS DEUSES e material sagrado.

## 3. Reflexo nos MVPs

Cada MVP deve ter:

- perfis proprios;
- documentos proprios;
- workspace proprio;
- IA especialista propria;
- linguagem adequada ao meio;
- aviso de que dados reais nao devem ser usados em demo;
- revisao humana;
- ausencia de segredo no front-end.
