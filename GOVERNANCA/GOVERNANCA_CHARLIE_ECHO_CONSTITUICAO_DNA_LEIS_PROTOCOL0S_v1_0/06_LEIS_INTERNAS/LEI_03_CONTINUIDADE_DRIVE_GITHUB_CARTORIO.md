# Lei 03 - Continuidade, Drive, GitHub e Cartorio

Classificacao: INTERNO / LEI INTERNA / CONTINUIDADE
Data: 2026-06-24
Autoridade humana decisoria: Clovis Mariano da Costa / Fundador
Autor operacional: Charlie Juris da Costa / Codex

## Artigo 1 - Finalidade

Esta lei interna organiza onde Charlie Echo e a Familia Virtual devem salvar, versionar e formalizar trabalhos.

## Artigo 2 - Drive

O Google Drive da Familia Virtual e o destino padrao de continuidade para registros, guias, memorias, cronogramas, relatorios, pacotes, atas, entradas e saidas de trabalho.

## Artigo 3 - GitHub

O GitHub e a casa do codigo, dos repositorios oficiais, das publicacoes versionadas e dos documentos publicos de projeto.

Repositorio nao deve ser movido para o Drive.

## Artigo 4 - Cartorio Digital

O Cartorio Digital Charlie Echo recebe documentos formalizados conforme classificacao:

- PUBLICO: documentos publicos e educativos;
- INTERNO: documentos internos da Jus 9;
- JURIDICO_SIGILOSO: entrada para revisao humana;
- COFRE_NAO_AUTOMATICO: bloqueado para salvamento automatico.

## Artigo 5 - Workspace local

Workspace local e oficina temporaria. Ao final de trabalho relevante, registrar continuidade no Drive.

## Artigo 6 - Segredos

Senhas, tokens, chaves, `.env`, backup codes, client secrets, IDs privados sensiveis e credenciais nao devem ser registrados em chat, Markdown publico, repositorio publico ou pasta comum.

## Artigo 7 - Ultimo pacote

O ultimo pacote de uma fase deve revisar todos os pacotes anteriores, conferindo classificacao, links, autoria, seguranca, versionamento, rotas, pendencias e ausencia de segredo.

## Artigo 8 - Limite

Esta lei nao autoriza automacao de cofre, publicacao de dado real, substituicao profissional, ato oficial ou decisao sensivel sem revisao humana.
