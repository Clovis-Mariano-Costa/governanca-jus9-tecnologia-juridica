# Versionamento - App MVP PWA e WhatsApp v1.0

Data: 2026-05-19

Pacote:

- criação do APP/PWA do MVP;
- manifesto instalável;
- service worker com cache básico;
- página offline;
- tela de entrada `app.html`;
- módulo demonstrativo `app-whatsapp.html`;
- parser local de `.txt` exportado do WhatsApp, sem upload;
- inventário privado da pasta WhatsApp mantido fora de publicação pública.

Observação:

Este pacote não cria backend real, autenticação real, banco de dados real nem criptografia de produção. O APP é demonstrativo e deve usar somente dados fictícios em ambiente público.
